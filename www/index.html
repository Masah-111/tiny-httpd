SERVED BY C · NO FRAMEWORK

このページは自作のHTTPサーバが返しています

あなたのブラウザがいま表示しているこのHTMLは、Apache でも nginx でもなく、 C言語で TCP ソケットから書き起こした tiny-httpd が配信しています。

いま起きたこと（HTTPの流れ）

ブラウザ → TCP接続 (3ウェイハンドシェイク)
→ "GET / HTTP/1.1" を送信
→ サーバがリクエストをパース
→ www/index.html を読み、ステータス行＋ヘッダ＋本文を返す
→ ブラウザが描画

実装しているもの

GET / HEAD・静的ファイル配信・Content-Type判定・パストラバーサル防御・ 200/400/403/404/405 応答。すべて標準ライブラリのみ。

ソースコード: github.com/Masah-111/tiny-httpd
